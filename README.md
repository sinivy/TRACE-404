> Nem toda evidência conta a verdade. Nem todo investigador está procurando por justiça.

**TRACE//404** é uma experiência narrativa interativa em formato de terminal, na qual o jogador assume o papel de um investigador anônimo encarregado de solucionar o assassinato de um bilionário.

Por meio de arquivos confidenciais, registros de acesso, fragmentos de câmeras e depoimentos, o jogador precisa reconstruir os acontecimentos, identificar contradições e descobrir quem está por trás do crime.

Mas existe algo errado nessa investigação.

---

## `01 // O CASO`

**Vítima:** Augusto Valença  
**Idade:** 61 anos  
**Ocupação:** Presidente do Grupo Valença  
**Classificação:** Homicídio  
**Status:** Investigação em andamento

Augusto Valença foi encontrado morto em sua residência.

Nos dias anteriores ao assassinato, uma auditoria independente começou a investigar transferências financeiras suspeitas realizadas por empresas ligadas ao seu conglomerado.

As movimentações levantaram suspeitas de financiamento indireto de operações em regiões de conflito, incluindo possíveis conexões com um grupo de guerrilha conhecido como Frente de Libertação de Aram.

Três pessoas estão sob investigação.

O acesso ao servidor foi concedido. Os documentos foram recuperados.

Agora, cabe a você descobrir o que realmente aconteceu.

## `02 // FUNCIONALIDADES`

- Interface inspirada em terminais Linux antigos.
- Efeito de digitação das mensagens.
- Sistema de comandos interativos.
- Arquivos confidenciais para consulta.
- Dossiês individuais de suspeitos.
- Inventário e cruzamento de evidências.
- Sistema de acusações.
- Múltiplos desfechos, incluindo um final secreto.
- Interface adaptável para computadores e dispositivos móveis.

## `03 // COMANDOS`

| Comando | Função |
|---|---|
| `ajuda` | Lista os comandos disponíveis |
| `iniciar` | Inicia a investigação |
| `limpar` | Limpa o terminal |
| `arquivos` | Lista os documentos recuperados |
| `abrir` | Abre um arquivo confidencial |
| `suspeitos` | Lista os investigados |
| `investigar` | Consulta o dossiê de um suspeito |
| `evidencias` | Consulta as pistas coletadas |
| `analisar` | Cruza as informações disponíveis |
| `acusar` | Formaliza uma acusação |
| `rastrear origem` | Investiga a origem da conexão |
| `confessar` | Acessa um registro oculto |

## `04 // TECNOLOGIAS`

O projeto foi desenvolvido utilizando tecnologias web nativas, sem frameworks.

- **HTML5** — estrutura da aplicação.
- **CSS3** — interface, responsividade e identidade visual.
- **JavaScript** — lógica do terminal, comandos e progressão narrativa.

## `05 // EXECUÇÃO LOCAL`

Não é necessário instalar dependências.

1. Clone o repositório:

```bash
git clone https://github.com/sinivy/TRACE-404.git
```

2. Entre na pasta:

```bash
cd TRACE-404
```

3. Abra o arquivo `index.html` no navegador.

Também é possível executar o projeto utilizando a extensão Live Server no Visual Studio Code.
